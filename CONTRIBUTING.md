# Contribuir a Movilidad

Este proyecto ciudadano lo mantienen vecinos y voluntarios de [Aldea Pucela](https://aldeapucela.org/). La documentación en español, las pruebas y los comentarios claros forman parte de las contribuciones.

**Todas las issues se centralizan en [biki-stats-core](https://github.com/aldeapucela/biki-stats-core/issues)** aunque la implementación se realice en este u otro repositorio.

Antes de comenzar una issue, consulta [la guía de desarrollo](docs/GUIA_DESARROLLO.md) y [AGENTS.md](AGENTS.md). Codex debe seguir la [skill de planificación](.agents/skills/github-issue-plan-first/SKILL.md): leer la issue, crear un plan, resolver dudas y solicitar autorización **explícita para escribir código**. Solo entonces crear una rama desde `main`, con formato `{feat|fix}/{issueId}/{titulo}`, y presentar PR contra `main`.

Commits:

```text
{feat|fix}: {título}
{descripción}
Refs: https://github.com/aldeapucela/biki-stats-core/issues/{issueId}
```
